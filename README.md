# Google Search Ranking & Discoverability Capstone

Lane: Refresh / Content Opportunity Scoring. Predicts which pages are likely to decline next so they can be reviewed first.

- `work/` holds every assignment notebook plus `capstone.ipynb` (add your weekly notebooks here).
- `docs/index.html` is the research paper, served by GitHub Pages. Charts live in `docs/figures/`.
- `submission/paper_url.txt` holds one line: the deployed paper URL.

Reproduce: open `work/capstone.ipynb` in Colab and run all cells. Raw data is downloaded to `data/` and never committed.

Built on the FlyRank ML Internship dataset (https://flyrank.ai). Anonymized research use only; no raw exports, client names or private queries are published.****
